Interactive VTK time-series visualization of morphing disk. Use the controls below to play, pause, step through timesteps, and change the color mapping. Mouse: drag to rotate, scroll to zoom, right-drag to pan.

Simulation of Koiter shell models using a spectral global parameterization to embed incompatible strains on soft thin shell structures. Both datasets use the same governing equations but differ in the parameterization:

  • DHA Morph — Disk harmonics (Shaqfa, Choi & Beyer, 2024, J. Comput. Phys.)
  • SOH Morph — Spheroidal harmonics (Shaqfa & van Rees, 2024, Constr. Build. Mater.)

Color maps show actuation, bending moments, and membrane forces across morphing stages.

Data loaded from assets/data/DHA_morph_vtkjs/ (converted VTU → vtk.js JSON).
To update after changing source VTU files: python3 scripts/convert_vtu_to_vtkjs.py then cd visualization && npm run build
